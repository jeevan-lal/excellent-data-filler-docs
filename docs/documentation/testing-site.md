# Testing Sites

Live test forms, framework samples, and sandbox environments designed for testing Excellent Data Filler automation workflows.

## Testing Sites & Frameworks

- [CTechHindi Example Forms](https://formfiller.ctechhindi.in/example/) — Comprehensive form collection covering all standard HTML inputs, file uploads, dialogs, and tables.
- [HTML Tables Example](https://formfiller.ctechhindi.in/example/example-26.php) — Dedicated tabular data extraction and row filling test page.
- [Vuetify 2 Form Example](https://vuetify-2-form-example.vercel.app/) — Vue.js Vuetify 2 UI component test suite.
- [Vuetify 3 Form Example](https://vuetify-3-form-example.vercel.app/) — Modern Vuetify 3 component library testing.
- [MUI 5 Form Example](https://mui-5-form-example.vercel.app/) — React Material-UI (MUI v5) form components.
- [Angular Material 14 Form Example](https://angular-material-14-form-example.vercel.app/) — Angular Material form fields, dropdowns, and datepickers.
- [Kendo UI Form Example](https://kendo-ui-form-example.vercel.app/) — Kendo UI widget and dynamic controls suite.
- [Microsoft Form](https://forms.office.com/Pages/ResponsePage.aspx?id=DQSIkWdsW0yxEjajBLZtrQAAAAAAAAAAAAN__gSPoL5UN1g2NVEyWk9TVEpTRUZTWVpSUUxYSzg3TS4u) — Enterprise Microsoft Forms automation test.
- [Google Form](https://docs.google.com/forms/d/e/1FAIpQLSdZm9QYVZ73w-MawGpHMIZY9oMvGHy8yVDYpZ_XXXQakDwKLQ/viewform) — Multi-page Google Forms automated submission.
